# Учет посещений (Attendance Tracker)

Простое консольное приложение на Python для учета посещений студентов. Данные хранятся в формате CSV.

## Возможности
- Добавление записей о посещении (присутствует, отсутствует, опоздал).
- Просмотр всех сохраненных записей.
- Автоматическое создание файла данных при первом запуске.

## Структура проекта
- `attendance.py` — основной скрипт приложения.
- `attendance.csv.example` — пример формата файла с данными.
- `README.md` — документация проекта.
- `.gitignore` — настройки игнорирования файлов для Git.

## Как использовать
1. Убедитесь, что у вас установлен Python 3.
2. Запустите скрипт в терминале:
   ```bash
   python attendance.py
